# MP3 Metadata Editor

Программа для редактирования метаданных MP3 файлов с графическим интерфейсом.

## Функциональность

- 📁 Выбор директории с MP3 файлами
- 🎵 Просмотр списка всех MP3 файлов
- ✏️ Редактирование метаданных:
  - Исполнитель (Artist)
  - Альбом (Album)
  - Год выпуска (Date)
  - Жанр (Genre)
  - Обложка (Cover Art)
- 💾 Сохранение метаданных для отдельного файла
- 🔄 Применение одинаковых метаданных ко всем файлам в директории

## 🚀 Быстрый старт (готовый .exe файл)

### Способ 1: Использование готового исполняемого файла (самый простой)

1. Скачайте или получите файл `MP3 Metadata Editor.exe` из папки `dist`
2. Двойной клик на файл `.exe` для запуска
3. **ВАЖНО:** Python не требуется!
4. Программа будет работать на любом Windows ПК

> Если файл не найден, см. раздел "Сборка .exe файла"

## 📦 Сборка .exe файла для Windows

### Требования
- Windows (Windows 7 и выше)
- Python 3.7+ (только для сборки, не требуется для использования готового .exe)

### Шаг 1: Подготовка исходного кода

1. Убедитесь, что у вас есть все файлы:
   - `mp3_metadata_editor.py`
   - `requirements.txt`
   - `build.bat`

2. Откройте командную строку (cmd.exe) в папке с программой

### Шаг 2: Построение исполняемого файла

**Способ 1 (самый простой - на Windows):**

Двойной клик на файл `build.bat` - скрипт автоматически:
- Установит PyInstaller
- Установит все зависимости
- Создаст .exe файл

**Способ 2 (вручную в командной строке):**

```bash
pip install -r requirements.txt
pip install pyinstaller

pyinstaller --onefile --windowed --name="MP3 Metadata Editor" mp3_metadata_editor.py
```

### Шаг 3: Получение .exe файла

После успешной сборки файл `MP3 Metadata Editor.exe` будет находиться в папке:
```
dist\MP3 Metadata Editor.exe
```

Этот файл вы можете:
- ✅ Запустить сразу
- ✅ Отправить друзьям
- ✅ Скопировать на другие ПК
- ✅ Расположить в любой папке

### Руководство по сборке (пошагово)

1. Откройте папку с программой в Windows Explorer
2. Нажмите на адресную строку, введите `cmd` и нажмите Enter - откроется командная строка
3. Введите команду: `build.bat`
4. Дождитесь сообщения "Build successful!"
5. Файл .exe будет в папке `dist`

NOTE: The `build.bat` script will attempt to use `app.ico` as the application icon if that file exists in the project root. If `app.ico` is missing the script will build without a custom icon to avoid the PyInstaller error:

```
FileNotFoundError: Icon input file ... app.ico not found
```

If you want a custom icon include an `app.ico` file in the same folder as the project before running `build.bat`.

## 📖 Руководство пользователя

### Для версии с Python установленным:

**Быстрый запуск:**
```bash
run.bat
```

**Или вручную:**
```bash
pip install -r requirements.txt
python mp3_metadata_editor.py
```

### Использование программы

1. **Выберите директорию** 
   - Нажмите кнопку "Выбрать директорию"
   - Выберите папку с MP3 файлами
   - Программа автоматически загрузит все MP3 файлы

2. **(опционально) Удаление номера из имени файла**
   - Если ваши файлы названы с номером в начале (например, "01. Track.mp3"), включите чекбокс
     "Удалять номер в названии файла" прямо в метаданах перед сохранением.
   - При сохранении выбранного или всех треков номера будут автоматически удалены и
     имена файлов будут переименованы на диске.

3. **Просмотр файлов**
   - Все MP3 файлы отобразятся в списке
   - Нажмите на файл, чтобы выбрать его

3. **Редактирование метаданных**
   - **Исполнитель** - имя певца/группы
   - **Альбом** - название альбома
   - **Год выпуска** - год (например, 2024)
   - **Жанр** - жанр музыки (например, Pop, Hip-Hop)
   - **Обложка** - обложка альбома (JPG или PNG)

   > Поля можно оставлять пустыми: если какое-либо поле не заполнено, текущие теги в файле
   > сохранятся без изменений. Пустые поля не стирают существующие значения.

4. **Сохранение данных**
   - Нажмите "Сохранить текущий" - сохранить только для выбранного файла
   - Нажмите "Применить ко всем" - применить одинаковые данные ко всем файлам

### Навигация

- **◀ Предыдущий** - Перейти к предыдущему файлу
- **Следующий ▶** - Перейти к следующему файлу
- **Клик на файл в списке** - Выбрать его

## Поддерживаемые форматы обложек

- JPEG (.jpg, .jpeg)
- PNG (.png)

## Техническая информация

- **Язык программирования:** Python 3.7+
- **GUI:**  tkinter (встроена в Python)
- **Работа с MP3:** mutagen
- **Обработка изображений:** Pillow
- **Сборка в .exe:** PyInstaller

## Примечания

- Программа использует ID3v2 теги для сохранения метаданных
- При применении обложки ко всем файлам используется одно и то же изображение
- Все введенные данные сохраняются с помощью стандартного формата ID3v2
- Готовый .exe файл полностью независим и не требует Python

## Решение проблем

### Проблема: "Python не найден"
**Решение:** Установите Python с сайта python.org и убедитесь, что выбрали опцию "Add Python to PATH"

### Проблема: "ModuleNotFoundError"
**Решение:** Убедитесь, что установлены все зависимости:
```bash
pip install -r requirements.txt
```

### Проблема: PyInstaller создает слишком большой файл
**Решение:** Это нормально, .exe файл включает всю среду Python (~100-150 МБ). Вы можете сжать его архиватором.

### Проблема: Антивирус блокирует .exe
**Решение:** Это ложное срабатывание. Добавьте программу в исключения антивируса.
